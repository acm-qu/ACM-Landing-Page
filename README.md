# ACM Qatar University Chapter - Landing Page
Repository of our landing page, a quick overview of the main benefits and features of our club.  
  
## How to contribute  

### Modify content  
- Navigate to src/app/<the page you want to modify>  
- Find `content.ts`
- Modify the desired content and make a PR
  
### Development
- Refer to src/app/hero and sec/app/our-projects for the folder organizing convention
- Do not directly commit, only make PRs
- Refer to src/app/globals.css for fonts and colors
